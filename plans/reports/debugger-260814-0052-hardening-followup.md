# Debugger follow-up — production hardening overlay

## Root-cause fixes applied

- Evidence capture now records missing commands as failed sections, requires
  screenshot artifacts when a screenshot is declared, and resolves source and
  GitOps SHAs when callers do not provide them.
- Feature and drift APIs expose `/healthz`, `/readyz`, and Prometheus text
  metrics compatible with the ServiceMonitor, KEDA, and rollout queries.
- The two API values directories are now generated by the GitOps ApplicationSet;
  catalog/workflow paths point at those environment-owned values.
- Kyverno digest and signature policies are `Enforce`; keyless signatures from
  both `main` and `dev` are accepted. Kafka persistence uses Apache Kafka's
  `/var/lib/kafka/data` path and TCP probes.
- Supply-chain verification rejects empty/non-JSON cosign output and uses a
  repository-scoped default identity. MLflow records the reproducibility
  manifest on a real registry run. Fork pull-request builds no longer attempt
  a secret-dependent GHCR login.
- `run_phase2_quality_gates.py --require-real-digests` now exposes the strict
  registry gate instead of silently running the grandfathered shape-only gate.
