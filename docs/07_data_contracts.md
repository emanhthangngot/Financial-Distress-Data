# 07 Data Contracts - Phase 1 Governance Lite

## Objective

This document is the single source of truth for every Bronze, Silver, and Gold
table produced by the Financial Distress Data pipeline. For each table it
records:

- schema (column name, dtype, nullability)
- owner (the DAG that writes it)
- source (the upstream dataset or API)
- refresh cadence (the Airflow schedule that triggers the writer)
- primary keys (deduplication key)
- expected row count range (smoke-test band)
- partition columns (MinIO/S3A layout)
- upstream tables (immediate predecessors in the same lakehouse)
- downstream consumers (DuckDB views, DAG tasks, evidence scripts)

It is consumed by ``src/quality/contract_checker.py`` which validates an actual
schema (e.g. read back from a Gold Parquet via DuckDB) against the contract
and raises on mismatch. Six evidence JSONs are produced under
``docs/evidence/governance/`` (3 lineage + 3 validation, one per DP) and are
regenerated by ``dags/09_data_governance.py`` on every run.

This is a Phase-1-equivalent alternative to DataHub. Phase 2 can layer a
DataHub/OpenLineage platform on top of the same contracts without changing
the file format.

| Field | Value |
| --- | --- |
| Owner DAG | ``dags/01_collect_company_master_data.py`` |
| Source | TCBS public company list (``src/collectors/company_list_collector.py``) |

## Lineage DP1

DP1 ingests raw source data, lands it in Bronze, deduplicates in Silver, and
projects a conformed ``dim_company`` to Gold. Upstream / downstream for each
DP1 output:

| Dataset | Upstream | Downstream |
| --- | --- | --- |
| `raw_company` | TCBS company list API | `stg_company`, `dim_company` |
| `raw_financial_statement` | TCBS financial statement API | `stg_company_quarter` |
| `raw_market_price` | TCBS market price API | `stg_company` |
| `stg_company` | `raw_company`, `raw_market_price` | `dim_company` |
| `stg_company_quarter` | `raw_financial_statement` | `fact_company_quarter_financials` |
| `dim_company` | `stg_company` | All Gold joins |

## Lineage DP2

DP2 pivots Silver financials into a Gold OBT and joins with the distress
labels to produce the denormalized one-big-table for the ML team.

| Dataset | Upstream | Downstream |
| --- | --- | --- |
| `fact_company_quarter_financials` | `stg_company_quarter` | `obt_company_quarter_risk` |
| `obt_company_quarter_risk` | `fact_company_quarter_financials`, `distress_labels`, `dim_company` | Phase 2 ML training |
| `dim_company` (DP2 view) | `stg_company` | OBT join, all feature tables |

## Lineage DP3

DP3 builds model-ready feature tables by computing rolling windows on
financial, market, and news data and joining them into a unified feature
table.

| Dataset | Upstream | Downstream |
| --- | --- | --- |
| `feat_company_financial_4q` | `fact_financial_statement` | `feat_company_unified` |
| `feat_company_market_30d` | `fact_market_price`, `fact_market_alert` | `feat_company_unified` |
| `feat_company_news_30d` | `fact_news_sentiment` | `feat_company_unified` |
| `feat_company_unified` | `feat_company_financial_4q`, `feat_company_market_30d`, `feat_company_news_30d` | Phase 2 ML training |
