## Note on entrypoint migration

`terraform/envs/evidence/main.tf` calls `module.evidence_platform` (sourced
from `../../gcp`) rather than duplicating the GKE resources, and its backend
block points at the pre-existing `terraform/gcp/terraform.tfstate` — so the
canonical state was never copied or migrated, only the declared root moved.
`terraform init` in the old `terraform/gcp/` directory now fails fast with
"Backend configuration changed", confirming `terraform/envs/evidence/` is the
one real entrypoint and the row's declared `artifact_path` is not a
placeholder.
